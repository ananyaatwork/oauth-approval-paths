# App selection

The library is chosen for **variety of setup challenge**, not popularity: each app shows a different kind of wait or gate. The tiers below are hypotheses until each app is researched.

## Library (10)

| # | App | Challenge it demonstrates | Status |
|---|---|---|---|
| 1 | GitHub | Easy for the developer; the wait is each customer's org owner | researched |
| 2 | Slack | Works at once, but there's a 10-workspace gate before Marketplace review (up to 10 weeks) and rate limits off-Marketplace | researched |
| 3 | Google (Gmail/Drive/Calendar) | Three paths by scope tier; restricted scopes need a paid annual CASA assessment | researched |
| 4 | QuickBooks Online | Sandbox only until a questionnaire is approved; no stated review time | researched |
| 5 | Microsoft (Entra / Graph) | Publisher verification plus per-tenant admin consent | researched |
| 6 | Salesforce | Connected/External Client App; AppExchange security review is paid and slow | researched |
| 7 | HubSpot | Public app with install caps before Marketplace listing | researched |
| 8 | Notion | No review for OAuth; permanent install-scope choice and page-level sharing are the traps (corrected: no company/privacy fields in the current portal) | researched |
| 9 | Zoom | Unpublished apps limited to your own account; Marketplace review to publish | researched |
| 10 | LinkedIn | Partner-gated: basic sign-in is self-serve, while most data APIs need a program application | researched |

## Live-generation rehearsal (not pre-built)

These are used only to test the live agent. They run in Block C, the way a reviewer would.

- **Linear** — likely easy and well documented.
- **Dropbox** — has a production-approval step.
- **Gusto** — partner-gated, with thin public docs. This tests whether the agent says "couldn't confirm" instead of guessing.
